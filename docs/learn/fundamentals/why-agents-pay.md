# Agent 为什么需要花钱

在传统的软件架构中，人类工程师或管理员手动配置 API Key 并预先绑定信用卡。然而，随着自主智能体（Autonomous Agents）的普及，Agent 需要在无人值守的情况下自主完成复杂工作流：

1. **按需购买高价值数据**：实时金融数据流、专业行业数据库、付费搜索引擎接口。
2. **调度高算力资源**：专用微调模型推理、代码沙盒执行环境、跨链状态验证。
3. **委托下游子智能体协作**：在多 Agent 协同网络中，Agent 之间需要通过对价支付建立可信经济激励，防止垃圾请求与服务滥用。

AgentPay 通过网关代理层拦截上游付费请求，在保护私钥与预算安全的前提下，让 Agent 获得即时、细粒度的微支付能力。详见 [项目概览](/guide/overview)。
:::
