# HTTP 402 与 x402 协议

HTTP 协议在诞生之初就保留了状态码 `402 Payment Required`，旨在用于未来的数字微支付系统。

## x402 协议标准

x402 协议在此基础上规范化了机器之间的即时支付协商流程：
1. **探测请求**：客户端请求受保护资源，服务端返回 `HTTP 402` 附带支付报价与参数（如接收地址、金额、资产网络、超时时限）。
2. **结算授权**：客户端验证报价并生成支付凭证（如链上交易签名或网关授权 Token）。
3. **重试交付**：客户端携带 `Authorization` 或 `X-Payment` 请求头重新发起请求，服务端验证后放行数据。
