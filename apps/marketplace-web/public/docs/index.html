AgentPayFinancial Firewall & Autonomous Payment Gateway for AI Agents

Empower AI agents to pay autonomously without exceeding financial authorization. Dual-path micro-settlements powered by HTTP 402 / x402 and internal virtual wallets.

🛡️ Financial Firewall

LLMs only propose payments; cryptographic signing and budget deductions execute behind an out-of-band policy engine. Per-tx caps, 24h rolling budgets, whitelists, and circuit breakers.

⚡ Dual-Path Settlements

On-chain x402 (EIP-3009 offline signing with zero gas token requirements for buyers) and internal virtual wallets (Hold → Fulfill → Capture/Release). Never silently downgrades on insufficient balance.

🔄 Tri-State Orthogonal State Machine

Strict separation of Payment Intent, Settlement, and Fulfillment. Network timeouts transition to explicit Unknown state, preventing double-spending and loss.

🏢 Multitenant Governance

Tenant, project, and member RBAC isolation. Key lifecycle management, draft configurations, immutable snapshot publishing, and sub-second rollbacks.

👁️ Agent Identity & Audit Trail

Cryptographic identity verified via credentials; strict separation of observed vs self-reported metadata. Append-only event logs, timeline tracking, and emergency kill-switches.

📒 Append-Only Double-Entry Ledger

Integer-based atomic currency units (micro-USDC). Immutable journal entries, multi-level automated reconciliation, and auditable accounting exports.

Experimental Project

AgentPay is under active development and has not been audited by an independent security firm. Evaluate exclusively on testnets and with test tokens. Do not use with production funds.
