ADR-001: x402 V2 协议与官方 SDK 架构策略（“复用 vs. 自研实现”） ​

  • 状态： 已采纳 (Accepted)
  • 日期： 2026-10-16
  • 决策者： AgentPay 核心架构工作组
  • 关联任务： 2026 年底规划 (任务 T0.2, T3.1)

1. 背景与问题陈述 ​

x402 是针对 HTTP 402 Payment Required 微支付的开放标准协议（由 x402 基金会维护）。在当前 2026 生态中：

  1. 协议规范现状： x402 V2 规范定义了 CAIP-2 链标识符、EIP-712/3009 转账授权，以及结构化的 PAYMENT-REQUIRED 与 PAYMENT-SIGNATURE 请求头。
  2. 官方 Python SDK 现状： PyPI 上已存在基础的 x402 包（含 x402[httpx]、x402[requests] 等可选扩展），提供基础的挑战提取与原始签名绑定。
  3. AgentPay 核心差异化定位：
    • 官方 SDK 本质上是一个原始传输层封装（Raw Transport Wrapper）：只要遇到 HTTP 402，就会无条件签名并付款。
    • AgentPay 则定位为自主金融防火墙与容错基础设施层（Autonomous Financial Firewall & Fault-Tolerant Infrastructure Layer）：其核心价值在于确定性策略评估（单笔上限、滚动预算、白名单、循环熔断器与两阶段原子预留）以及解耦的三态恢复引擎。

2. 备选方案评估 ​

评估维度方案 A：强依赖官方 SDK (x402)方案 B：完全从零自研实现方案 C（推荐）：分层适配 + 自研防火墙核心
金融防火墙集成困难。官方拦截器缺少两阶段预留（reserve -> commit -> release）生命周期钩子。完全自主；拦截器与策略引擎无缝协同。优秀。 完整生命周期拦截器，且与上游协议格式严格对齐。
依赖体积与冲突笨重。容易引入传递性的 web3 与加密库版本冲突。极简（httpx、pydantic、eth-account）。极简。 核心包零冗余依赖，官方 SDK 仅作为纯可选扩展。
上游规范对齐度自动继承上游补丁。协议头变更时需手动对齐。高。 标准 Pydantic 模型通过上游测试向量持续验证。
实现风险与开发效率初期快但改造防火墙状态机风险高。适中（约 200 行 Pydantic 编解码）。最优（约 3 小时完成清晰模型，零黑盒调试成本）。

3. 决策结果 ​

我们决定采用 方案 C（分层适配架构）：

3.1 核心协议编解码 (agentpay-core) — 原生 Pydantic V2 模型 ​

  • 我们不将第三方 x402 PyPI 包作为强依赖。
  • 使用 Pydantic V2 原生定义 PaymentChallenge 与 PaymentAuthorization 模型，严格遵循 x402 V2 标准。
  • 100% 字节级一致： 序列化与反序列化行为通过标准测试向量（specs/conformance/test-vectors/）验证。
  • 收益： 消除依赖冲突与运行时黑盒，保证最佳测试执行速度与透明调试体验。

3.2 网络拦截器与签名生命周期 (agentpay-client) — 自研编排 ​

  • 实现自主可控的 httpx 传输层拦截器。
  • 客户端严格编排完整的金融生命周期： $$\text{拦截 402} \longrightarrow \text{策略评估与预算预留} \longrightarrow \text{签署授权} \longrightarrow \text{携带 PAYMENT-SIGNATURE 重放} \longrightarrow \text{提交或释放预留}$$

3.3 上游互操作扩展 (x402-interop) — 可选扩展 ​

  • 提供辅助转换工具，支持在 AgentPay 原生挑战/授权对象与官方 x402 库对象之间双向转换，确保同时安装两者的用户可无缝互操作。

4. 后续影响与风险应对 ​

  • 正向影响：
    • 任务 T3.1 的实现工作量严格可控（$\le 3$ 小时）。
    • 两阶段预留（reserve -> commit -> release）直接内嵌到 HTTP 传输生命周期中，无需侵入式 Hack。
    • Python SDK 保持极度轻量，冷启动极快。
  • 风险与缓解：
    • 风险： 上游 x402 V2 规范发生破坏性 Schema 变更。
    • 缓解： 在 GitHub Actions 中使用跨语言 JSON 测试向量执行持续自动化一致性测试，及时捕获 Schema 漂移。
