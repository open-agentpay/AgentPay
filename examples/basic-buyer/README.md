# Basic Buyer Example

This example demonstrates how an autonomous AI agent uses the `agentpay` Python client SDK to query a paid API protected by x402 V2.

## Key Capabilities Demonstrated:
- Local EVM wallet generation & signing (`LocalSigner`)
- Policy budget configuration (`PolicyConfig`)
- Transparent HTTP 402 challenge negotiation & payment (`AgentPayClient`)
- Automatic quota reservation and commit

## Usage:
```bash
python main.py
```
