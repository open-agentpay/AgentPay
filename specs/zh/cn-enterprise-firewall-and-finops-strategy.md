## 1. 战略洞察与认知统一

### 1.1 核心壁垒认知重构
在技术与市场认知上，必须明确：**底层的结算通道（无论是海外的 EIP-3009/USDC，还是国内的微信/支付宝/网银转账）只是可插拔的资金通道；AgentPay 的核心不可替代壁垒在于位于 AI 智能与资金资源之间的「金融防火墙（Financial Firewall）」、「三态防悬挂状态机（Hold/Capture/Release）」以及「不可篡改行为审计黑匣子」**。

### 1.2 为什么必须彻底重塑国内定位？
- **摒弃“Web3 机器自主乌托邦”假象**：国内没有大量自治 Agent 自发互相买卖工具的土壤；更关键的是，“代币、链上清算、无牌照资金池”触碰国内合规红线，严肃政企客户会直接一票否决。
- **直击国内企业的真实恐慌**：国内大模型应用正从“技术尝鲜”进入“业务实战”，企业老板、CTO 和财务总监普遍面临三大焦虑：
  1. **账单恐怖片（Runaway Loop）**：Agent 因 Prompt 注入或代码死循环，半夜刷爆商业模型与外部高价值 API（如企查查/万方/短信核验），欠费停机。
  2. **财务一团烂账**：月底几十万 AI 开销，分不清哪个部门、哪个智能体花的，无法对账，无法按部门切分预算，更无法开具合规增值税专票。
  3. **合规背锅风险**：等保 2.0 与网安合规审查时，纯应用层日志（Prompt Log）可被篡改，无法提供具备法律效力的外部调用留痕与人工审批链路。

## 3. 国内版产品核心架构：“防、控、审、算”四部曲

```
                              ┌────────────────────────────────────────┐
                              │ AgentPay: 企业级 AI 行为审计与资金防火墙│
                              └───────────────────┬────────────────────┘
             ┌─────────────────────┬──────────────┴───────┬─────────────────────┐
             ▼                     ▼                      ▼                     ▼
        【防：熔断防护】       【控：人在回路】        【审：合规留痕】       【算：FinOps 水表】
        • 死循环实时切断       • 飞书/企微审批卡片    • 不可篡改只追加事件   • 部门/项目/Agent 分级配额
        • 单笔/24h 额度封顶    • 402 异步挂起重放     • 网关客观事实(Observed)• 微信/支付宝/对公打款充值
        • Prompt 注入防盗刷    • 手机端一键放行       • 应对等保2.0合规导出  • 增值税发票与对账单导出
```

### 3.1 防（Financial Firewall & Circuit Breaker）
- **多层预算硬顶**：单笔调用上限（`single_tx_cap`）、24 小时滑动窗口预算（`max_amount_per_day`）。
- **异常频次熔断（RPM Circuit Breaker）**：检测到突发高频调用或连续报错，第 3 秒自动拉下安全电闸，物理掐断流量。
- **Prompt 注入防盗刷**：防止 Agent 被提示词诱导发起无节制的付费调用。

### 3.2 控（HITL Human-in-the-Loop）
- **三级风控梯度**：小额（$\le$ 阈值）毫秒级放行；中大额触发人工审批；超大额直接硬顶阻断。
- **办公协同无缝唤醒**：网关返回 `402 Payment Required` 挂起连接，异步向负责人的**飞书 / 企业微信 / 钉钉**推送富文本审批卡片（显示 Agent 身份、触发意图、预计消耗、所属项目）。
- **手机端一键决议**：负责人点击【批准】后，客户端 SDK 自动携带 `approval_id` 重放，原子执行预占扣款。

### 3.3 审（Behavior Audit & Blackbox）
- **观测（Observed）与自报（Declared）严格隔离**：网关网络层捕获的时间戳、TLS 证书指纹、状态码、真实扣费作为**法定唯一事实**；Agent 自报的 `session_id`、`task_id` 仅用于链路展示，严禁参与计费与权限决议。
- **不可篡改只追加（Append-Only）**：审计事件入库后禁止 Update/Delete，支持哈希链指纹防篡改。
- **一键停用电闸（Kill Switch）**：管理员在控制台点击暂停或撤销 Key，全网关节点在 1 秒内阻断该 Agent 后续一切新请求。

### 3.4 算（AI FinOps & Billing）
- **树状配额管控**：租户（企业） $\to$ 部门（研发/运营/销售） $\to$ 项目组 $\to$ 具体 Agent。
- **CNY 6 位微单位虚拟账本**：对齐国家法币体系，以人民币（分）充值，入账自动换算为 6 位微单位（1 元 = 1,000,000 base units），天然适配毫厘级微支付。
- **严守二清红线**：阶段一采用“内部算力/API 预付闭环”（不可提现、不可跨租户互转，零牌照风险）；阶段二演进为持牌机构（微信电商收付通/支付宝直付通/商业银行专户）空中合规分账。
- **财务闭环**：支持对公转账流水智能核销、月度消耗对账单导出，对接数电发票系统开具增值税普票/专票。

## 4. 与开源生态顶流的结合：集成 Langfuse 打造“AI 运维双子星”

我们明确**不重复造轮子**（不去重写一套 Prompt 管理与 LLM 评估系统），而是与 **MIT 开源协议的 Langfuse 深度共生**：

```
   ┌────────────────────────────────────────────────────────────────────────┐
   │                    【AI 全栈运维与安全双子星体系】                     │
   │                                                                        │
   │   【Langfuse (开源 MIT)】                   【AgentPay (核心网关)】     │
   │   • 负责看清楚 Agent 的“脑子”               • 负责管住 Agent 的“双手”   │
   │   • Prompt 版本与 Playground 调试           • 外部工具 (MCP) 出入口     │
   │   • Token 级链路追踪 (Tracing)              • 网络层死循环秒级熔断      │
   │   • 模型输出质量评估 (Eval)                 • 飞书/企微大额卡片审批     │
   │                                             • 真实法币 (Hold/Capture)   │
   └───────────────────────────────────┬────────────────────────────────────┘
                                       │ 原生打通机制
                                       ▼
   1. 链路透传: AgentPay 自动继承并关联 Langfuse 的 trace_id / span_id
   2. 账单回写: AgentPay 将真实扣费 (¥0.05) 与阻断事件异步回写给 Langfuse
   3. 私有化打包: 提供 docker-compose.enterprise.yml 一键拉起双引擎
```


### 6.2 3 分钟炸场 Live Demo 演示脚本
1. **失控惨剧**：现场启动接入商业付费 API 的 Agent，故意诱发死循环递归查询；终端疯狂刷屏，右上角欠费金额一路狂飙，数秒内欠费停机。
2. **挂载防火墙**：只改一行代码，将客户端请求代理至 `agentpay-gateway`。
3. **高光时刻**：
   - **防死循环**：第 3 秒，网关触发 RPM 熔断，红灯亮起，强制掐断网络调用；
